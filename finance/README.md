# 実質財務状況（実態BS）月次レポート

freee会計の貸借対照表に、オーナー指定の評価替えルールを当てて「実質純資産」を算出する仕組み。
毎月1日 6:38（日本時間）に自動実行され、結果がチャットとプッシュ通知で届く。

## ファイル

| ファイル | 役割 |
|---|---|
| `adjustments.json` | 評価替えルール（唯一の正）。金額・基準日・出典をここで管理する |
| `actual_net_assets.py` | freee の `GET /api/1/reports/trial_bs` のJSONにルールを当ててMarkdownを出す |
| `history.csv` | （任意）`--history` を付けて実行すると月次の純資産推移が1行ずつ溜まる |

## 計算式

```
実質純資産 = 帳簿純資産 + Σ(評価額 − 簿価)
```

- `mode: fair_value` … 対象科目の簿価合計を `value` に置き換える（差額 = value − 簿価）
- `mode: delta` … 対象科目に固定額 `value` を加減する
- 負債は帳簿のまま。帳簿純資産には当期の未確定利益が含まれる。

## 実行方法

```bash
# freee から貸借対照表を取得して trial_bs.json に保存したうえで
python3 finance/actual_net_assets.py --trial-bs trial_bs.json --rules finance/adjustments.json
# 履歴も残す場合
python3 finance/actual_net_assets.py --trial-bs trial_bs.json --rules finance/adjustments.json --history finance/history.csv
# RIOT を時価で評価する場合（adjustments.json の riot.market.shares を設定済みのとき）
python3 finance/actual_net_assets.py --trial-bs trial_bs.json --rules finance/adjustments.json --riot-price-jpy 1234.5
```

## ルールの更新手順

1. `adjustments.json` の該当項目の `value` を直す
2. `as_of` を更新日に、`source` を根拠（査定書、返戻金証明、証券口座の時価など）に書き換える
3. 基準日から `policy.stale_days`（90日）を過ぎた項目は、レポートに「要更新」と出る
