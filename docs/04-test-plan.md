# テスト計画

自動テストと手動検証を区別して報告する（設計書 14-10）。結果は `docs/05-test-report.md`。

## 自動テスト

### 静的検査
- `npm run typecheck`（tsc --noEmit）
- `npm run lint`（eslint, next/core-web-vitals + typescript）

### 単体（Vitest, `src/**/*.test.ts`）
| 対象 | 検証内容 | 受入テスト対応 |
| --- | --- | --- |
| `logic/growth` | 申告ごとの成長点、1 日上限 3 点、段階しきい値、単調増加（減点なし）、`rest`/`skip` で減らない、経過時間が結果に影響しない、章は帰還日数で決まる | 14-3, 14-4, 14-5 |
| `logic/suggest` | 常に 3 案、休息が必ず含まれる、重複しない | 2-B |
| `logic/time` | dayKey が端末ローカル日付、経過分の計算 | — |
| `store/storage` | 保存→読込→削除（fake-indexeddb）、削除後は null | 14-6, 14-7 |
| `content/story` | 7 章 × 3 申告 + エピローグのすべてにテキストがある。禁止語を含まない | 4 章 |

### E2E（Playwright, Chromium, 375×667）
| シナリオ | 受入テスト対応 |
| --- | --- |
| 導入 → 分身 → 部屋 → プレビュー（ラベル確認）→ 部屋。所要 3 分以内（テスト時間で確認） | 14-1 |
| 作戦会議 → 出発 → ページ再読込（閉じたことの代替）→ 出発中が続く → 帰還 → やった → 変化画面に前後の部屋と物語 → 部屋の段階が上がる | 14-2, 14-3 |
| 「今日は休んだ」でも成長が減らず物語が出る。「記録せず戻る」でも減らない | 14-4 |
| 同日に 4 回帰還しても成長は 3 点で止まり、罰や警告はない | 14-5 |
| オフライン: 一度表示後に offline にして再読込しても部屋が表示される。再起動後も保存されている | 14-6 |
| ニックネームなしで開始できる。設定から削除すると導入に戻り、記録が消える | 14-7 |
| ネットワーク送信が同一オリジンの静的取得以外にない（リクエストを監視） | 14-8 |
| キーボードのみで導入→部屋まで進める。主要ボタンに aria-label / 見出し構造がある | 14-9 |
