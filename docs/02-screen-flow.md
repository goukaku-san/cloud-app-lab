# 画面遷移

すべての画面は `/` 配下の静的ルート。遷移はクライアント側で行い、状態は端末内（IndexedDB）に保存される。

```
/            起動判定（プレイヤーなし→/intro、出発中→/journey、それ以外→/room）
/intro       導入: 作品の約束、任意のニックネーム → /avatar
/avatar      分身のカスタマイズ（髪型・服の色・相棒）→ /room
/room        鏡の部屋: 分身・世界・本日の状態。初回は「未来の部屋のプレビュー」を重ねて表示
             ├→ /plan     作戦会議: 3 案から選ぶ / 自分で決める → 出発
             │   └→ /journey  出発中: 閉じる案内、端末時計の経過、帰還 / 記録せず戻る
             │       └→ /return  帰還: やった / 少しやった / 今日は休んだ + ひとこと（任意）
             │           └→ /change  変化: ビフォー・アフター、物語、画像保存 → /room
             ├→ /avatar   姿を変える
             ├→ /quiz     一問の魔法（任意・デモ表示）: 4 択 → 正誤と解説 → 考え方の言語化（任意）
             ├→ /stars    共創の星図（架空のデモデータのみ）
             ├→ /log      旅の記録（本人のみ）: 7 日の振り返り、出発の記録、一問の魔法の記録
             └→ /settings 設定: 動き・文字サイズ・音（準備中）・通知（送らない）・データ削除 → /about
/about       保護者・説明: 自己申告の限界、AI の限界、広告方針、データの扱い
```

## ガード

- プレイヤー未作成で `/room` 以降に来た場合は `/intro` へ戻す。
- 出発中のセッションがある状態で `/room` や `/plan` に来た場合は `/journey` へ戻す（アプリを閉じて再起動しても出発中が続く）。
- `/change` は直前の帰還結果（`lastChange`）がない場合 `/room` へ戻す。

## 各画面の要点

| 画面 | 主要操作 | 禁止事項の反映 |
| --- | --- | --- |
| 導入 | ニックネームは任意。空でも開始できる | 個人情報の入力項目はニックネームのみ |
| 鏡の部屋 | 作戦会議へ / 姿を変える / 記録 / 設定 | 連続日数・ランキングを表示しない |
| プレビュー | 「これはプレビューです」のラベル付きで段階 3 の部屋を表示 | 成長点を付与しない |
| 作戦会議 | 3 案（勉強 / 復習か小さな一歩 / 休息）+ 自分で決める（1〜90 分） | 押し付けない。休息が常に選べる |
| 出発中 | 閉じる案内、経過時間（端末の時計）、帰還、記録せず戻る | 通知なし。途中離脱に罰なし |
| 帰還 | 3 つの自己申告 + ひとこと（任意、140 字） | 「できなかった」を責めない文言 |
| 変化 | 前後の部屋、物語、解放された物、画像保存 | 画像にニックネームを含めない。SNS 共有は未実装 |
| 記録 | 日付・行動・申告・分・ひとこと | 本人にだけ表示 |
| 設定 | 動き軽減、文字拡大、音（実験・初期 OFF・音量）、通知（送らない）、削除 | 削除は確認付きで完全削除 |
| 一問の魔法 | 4 択に答える → 正誤・解説 → 考え方（任意）→ もう一問 / 部屋へ | 成長点なし。順位・点数なし。「デモ（監修前）」を常時表示 |
| 星図 | 架空の星と、自分の帰還数の星 | 架空データと明示。個人の比較なし |
