# 公開準備メモ（承認待ち。公開作業は行っていない）

外部公開は設計書 0 章・15 章により承認が必要。本書は、承認後に必要となる作業の整理であり、ホスティングの契約・デプロイ・ストア申請は一切行っていない。

## 1. 配布形態

- `npm run build` が生成する `out/` は静的ファイルのみ。HTTPS で配信できる静的ホスティングならどこでも動く。
- 条件: サイトのルート（`/`）に置くこと。Service Worker（`/sw.js`）と manifest（`start_url: "/"`）がルート前提のため、サブパス配信には `basePath` の追加変更が必要。
- サーバー側の処理・データベース・環境変数は不要。API キーも存在しない。

## 3. 公開後に初めて必要になるもの（この版には含めない）

- 利用規約・プライバシーポリシーの掲載（端末内保存のみでも、保護者向けに明記が望ましい）
- 問い合わせ窓口
- 北極星指標の計測: 現状は計測しない。計測する場合は opt-in の匿名集計を設計し、プライバシー審査を通す
- Service Worker の `CACHE_VERSION` を更新ごとに上げる運用

## 4. 判断が必要な点

1. 配信先（候補: 静的ホスティング各社、または自社ドメイン直下）
2. ドメイン名と、保護者向け説明ページの公開有無
3. 学習問題の監修者と、監修後に `reviewed: true` へ更新する手順の担当
