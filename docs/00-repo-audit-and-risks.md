## 2. 採用した技術判断

| 判断 | 理由 |
| --- | --- |
| Next.js 16.4（App Router）+ `output: 'export'` の静的書き出し | ログインなし・端末内保存の初期版はサーバー不要。静的ファイルとして任意のホスティングに置ける。バックエンド追加時は `output` を外すだけで移行できる |
| Tailwind CSS 4 | 推奨構成。デザイントークンは `globals.css` の CSS 変数で一元管理 |
| 状態保存は IndexedDB を直接利用（ライブラリなし） | 未成年向けのため第三者依存を最小化。`StorageAdapter` インターフェースで抽象化し、将来の同期・サーバー保存に差し替え可能 |
| アニメーションは CSS/SVG のみ | Framer Motion は不採用（軽量化・依存削減）。`prefers-reduced-motion` と設定トグルの両方で停止 |
| Web フォントは使わない | 外部フォント取得を避け、端末のシステムフォントで表示。ビルド時のネットワーク依存もなくす |
| テスト: Vitest（単体）/ Playwright（E2E） | Playwright は環境同梱版（1.63.0）に合わせて固定 |
| 分析タグ・第三者 SDK | 入れない（設計書 12 章） |

## 4. 安全設計の実装状況（この版）

- 個人情報: ニックネーム（任意）以外は入力項目を設けない。学校名・位置情報・チャット・公開プロフィールはなし。
- 外部送信: ネットワーク送信を行うコードは存在しない（静的ファイルの取得のみ）。Service Worker は同一オリジンのみキャッシュ。
- 羞恥・罪悪感を利用する文言: 物語と UI 文言は「できなかった」「休んだ」を肯定的に扱う。単体テストで禁止語（例: 「サボ」「罰」「ダメ」）を検査する。
- 深夜の再訪促進・プッシュ通知: 実装しない。通知権限も要求しない。
- 依存性誘発: 可変報酬・ガチャ・ランキング・無限スクロールは実装しない。成長は決定的（同じ申告なら同じ結果）。
- 未成年向け広告: 実装しない。
