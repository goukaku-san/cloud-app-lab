# 実装計画（受験生の鏡 MVP）

設計書 v0.1 の 13 章に沿う。各 Phase の終わりに `npm run check`（typecheck / lint / unit）と `npm run test:e2e` を実行し、結果を `docs/05-test-report.md` に記録する。

## 技術構成（確定）

- Next.js 16.4 App Router / React 19 / TypeScript 5 / Tailwind CSS 4
- `output: 'export'` + `trailingSlash: true` で `out/` に静的書き出し
- 状態: React Context + `useReducer`。永続化は `StorageAdapter`（IndexedDB 実装 / メモリ実装）
- PWA: `public/manifest.webmanifest` + 手書き `public/sw.js`（同一オリジンのみ、本番ビルドでのみ登録）
- アニメーション: CSS のみ。`html.reduce-motion` と `prefers-reduced-motion` で停止
- テスト: Vitest（純粋ロジック・ストレージ・文言検査）、Playwright（スマホ幅 375×667 の E2E）

## ディレクトリ構成

```
src/app/            画面（ルート）。すべてクライアントコンポーネント
src/components/     鏡の部屋 SVG、分身 SVG、共通 UI
src/game/types.ts   データモデル
src/game/content/   クエスト候補、部屋の段階、14 日分の物語（草案）
src/game/logic/     純粋関数: 成長計算、提案、日付、時計
src/game/store/     StorageAdapter、GameProvider（Context）
e2e/                Playwright
public/             manifest, sw.js, icons
docs/               計画・設計・テスト報告
```

## ゲームロジックの規則（決定的・時間非依存）

| 規則 | 値 |
| --- | --- |
| 自己申告ごとの成長点 | やった 2 / 少しやった 1 / 今日は休んだ 1 / 記録しない 0 |
| 1 日の成長点上限 | 3 点（上限後も物語と記録は進む。罰なし） |
| 部屋の段階しきい値（累積成長点） | 0, 1, 3, 6, 10, 15 → 段階 0〜5 |
| 物語の章 | 帰還した日数（記録しない を除く）で決まる。1〜14 章、15 日目以降はエピローグ 7 本を巡回（1 週間で一巡） |
| 経過時間 | 記録のみ。成長点・段階・章に影響しない |
| 連続日数 | 保存も表示もしない |
| 減点 | 存在しない。成長点は単調増加 |
