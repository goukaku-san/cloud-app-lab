## 5. デモ動画用の操作シナリオ（約 2 分）

1. `npm run build && npm run start` で http://127.0.0.1:3100 を開く（スマホ幅のエミュレーションを推奨）。
2. 導入: 約束を読み、ニックネームを空のまま「はじめる」。
3. 分身: 髪型・服の色・相棒を選び「この姿にする」。
4. 部屋: 「未来の部屋のプレビュー」が出る。ラベルを見せてから「自分の部屋へ」。静かな部屋（段階 0）を見せる。
5. 作戦会議: 3 案から「数学を10分」などを選び、時間を +5 して「現実へ出発」。
6. 出発中: 「この画面は閉じて大丈夫」を見せ、ブラウザを閉じて開き直す（出発中が続く）。
7. 帰還: 「やった」を選び、ひとことを入れて「鏡を見る」。
8. 変化: 前 / 後の部屋、第 1 章の物語、「成長 +2」、現れたもの。画像保存ボタンを押す。
9. 部屋へ戻る: 灯りのともる部屋（段階 1）。
10. もう一度作戦会議 → 「休息する」を選んで出発 → 帰還 → 「今日は休んだ」。成長 +1 とひざ掛け、物語を見せる（罰がないことの説明）。
11. 旅の記録 → 設定（動きを減らす、文字を大きく）→ 保護者・説明 → 「すべてのデータを削除」で導入に戻る。

スクリーンショット: `docs/screenshots/` に E2E が自動保存したもの（01 導入〜13 設定）。
