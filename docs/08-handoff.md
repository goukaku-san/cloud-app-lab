## 4. 構成の要点

```
src/app/            画面。全部クライアントコンポーネント。useRouteGuard で遷移を守る
src/game/types.ts   データモデル（docs/03）
src/game/logic/     成長・提案・日付・季節・クイズの純粋関数
src/game/content/   部屋の段階と物、クエスト候補、物語（草案）、問題 30 問（AI 下書き・監修前）、星図デモ
src/game/store/     reducer（純粋）、GameProvider（IndexedDB 保存、送信待ちの処理）、storage
src/game/classroom/ 教室の星図の取り決め（protocol）、日替わりハッシュ、クライアント（mock / http）
server/             集計サーバー（Node 標準のみ、JSON ファイル保存）。npm run server
public/sw.js        Service Worker（同一オリジンのみ、配信先の基点はスコープから算出）
e2e/flow.spec.ts    E2E（スマホ幅）。スクリーンショットを docs/screenshots に保存
docs/               00 監査と R1〜R12、01 計画、02 画面、03 データ、04 テスト計画、05 テスト報告、06 公開準備、07 事業設計 v0.2
```

主なコマンド: `npm run check`（typecheck+lint+unit）、`npm run test:e2e`（ビルド込み）、`npm run build && npm run start`（http://127.0.0.1:3100）、`npm run server`（集計サーバー）。
サブパス配信は `NEXT_PUBLIC_BASE_PATH=/cloud-app-lab npm run build`。接続モードは `NEXT_PUBLIC_CLASSROOM_API=<URL>`（未設定ならモック）。

## 7. 前任が踏んだ落とし穴（再発防止）

- `pkill -f` / `pgrep -f` に自分のコマンド行が一致して自分を殺す。バックグラウンド起動は `& echo $! > pidfile` で PID を保存して kill する。
- `out/` は 1 つしかない。サブパスビルドとルートビルド、E2E の並行実行は衝突する。直列にする。
- Tailwind v4 で `className` に `text-sm` を足しても基底の `text-base` に負ける。サイズは props（`size="sm"`）で切り替える実装にしてある。
- ESLint の React ルール: 描画中の `Date.now()`、effect 内の同期 setState、描画中の ref 更新は全部エラー。`useSyncExternalStore` や `useState` 初期化子で回避。
- 画面遷移と同時に状態を変えると `useRouteGuard` が先に別画面へ飛ばす。`paused` を渡してから dispatch する。
- この環境の自動分類器は「公開面を作る」操作（Pages を自動配信するワークフローの push など）を止めることがある。止められたら、公開に関わらない部分だけ進め、オーナーに判断を求める。
- この環境から github.io へは接続できない（配信結果の目視確認は不可）。
- 文章中の「順位」などの語を E2E で禁止語として検査すると、説明文の正当な記述に誤検知する。検査対象を表やカードに絞る。
- `workflow_dispatch` だけのワークフローは既定ブランチにないと登録されず、API 実行は 404 になる。
- `github-pages` 環境は既定で `main` 以外からの配信をはじく（deploy ジョブが 2 秒で失敗、ログなし）。
